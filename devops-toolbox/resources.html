Recommended Resources

Books and gear that are actually worth owning if you work in this space — picked to match what the tools on this site are for, not a generic "best DevOps books" list. Amazon affiliate links; using them costs you nothing extra and helps keep these tools free.

AWS & Cloud

  • AWS Certified Solutions Architect study guides — worth it once you're past the CIDR Calculator stage and actually planning architecture, not just debugging one resource.
  • AWS Certified Security Specialty study guides — pairs well with the JWT Decoder, TLS Certificate Decoder, and Secret Scanner tools here.

Kubernetes

  • Kubernetes: Up & Running — still the most practical end-to-end reference for what the K8s Manifest Analyzer and Resource Quota Calculator are checking for.
  • CKA (Certified Kubernetes Administrator) study guides

Terraform & Infrastructure as Code

  • Terraform: Up & Running — the standard reference for anyone using the TF Plan Formatter here for real work, not just one-off snippets.

Git & Version Control

  • Pro Git — genuinely useful once you're past basic commits and into the territory the Conventional Commit and Changelog Generator tools are built for (real release workflows, not just `git add .`).

Hardware for a real home lab / on-call setup

  • Mechanical keyboards — if you're pasting YAML/JSON into these tools all day, this matters more than people admit.
  • Raspberry Pi kits — the cheapest real way to practice the Linux/Sysadmin side of this (LVM, cron, SELinux) without touching a cloud bill.
