DevOpsToolbox

Free tools that run entirely in your browser — nothing you paste is ever sent anywhere.

YAML Validator

Paste any YAML — Kubernetes manifests, Docker Compose, CI configs — and check it for syntax errors instantly. Runs fully client-side.

Paste YAML and click "Check YAML" to see the result here.

Terraform Plan Formatter

Paste raw terraform plan output (color codes lost from a copy-paste) and get it re-highlighted — creates in green, destroys in red, updates in yellow — so it's actually readable again.

Paste a plan and click "Format Plan" to see it highlighted here.
create destroy update in-place replace (destroy + create)

Cron Expression Explainer

Paste a 5-field cron expression and get a plain-English explanation of when it actually runs.

Enter a cron expression and click "Explain".
Field order: minute hour day-of-month month day-of-week

Markdown → Word Converter

Paste Markdown and download it as a real .docx file — headings, bold/italic, lists, code blocks, and tables all carry over. Conversion happens entirely in your browser; nothing is uploaded.

Paste Markdown and click convert — a preview of the formatted result will appear here, and a .docx file will download automatically.

JSON ↔ YAML Converter

Paste JSON or YAML and convert to the other format. Auto-detects which one you pasted.

Paste JSON or YAML, then pick a direction.

JSON Formatter & Validator

Validate, pretty-print, minify, or sort the keys of any JSON.

Paste JSON and pick an action.

Terraform Resource Counter

Paste Terraform code and get a tally of every resource type — useful for PR reviews and change-scope estimates.

Paste Terraform code and click "Count Resources".

Kubernetes Manifest Analyzer

Paste a Deployment, Pod, or similar manifest and get a lightweight lint check — missing resource limits, missing probes, privileged containers, :latest tags, and more.

Paste a manifest and click "Analyze".

Dockerfile Best-Practices Checker

Paste a Dockerfile and catch common issues: latest tags, running as root, unpinned installs, missing HEALTHCHECK, and more.

Paste a Dockerfile and click "Check".

AWS ARN Parser

Enter an ARN and click "Parse".

JWT Decoder

Paste a JWT and click "Decode".

Regex Tester

Enter a pattern and text, then click "Test".

Base64 / URL Encode & Decode

Paste text and pick an action.

Hash Generator

Generate MD5, SHA-1, SHA-256, and SHA-512 hashes of any text.

Paste text and click "Generate Hashes".
