DevOpsToolbox

Free tools that run entirely in your browser — nothing you paste is ever sent anywhere.

YAML Validator

Paste any YAML — Kubernetes manifests, Docker Compose, CI configs — and check it for syntax errors instantly. Runs fully client-side.

Paste YAML and click "Check YAML" to see the result here.

Terraform Plan Formatter

Paste raw terraform plan output (color codes lost from a copy-paste) and get it re-highlighted — creates in green, destroys in red, updates in yellow — so it's actually readable again.

Paste a plan and click "Format Plan" to see it highlighted here.
create destroy update in-place replace (destroy + create)

Cron Expression Explainer

Paste a 5-field cron expression and get a plain-English explanation of when it actually runs.

Enter a cron expression and click "Explain".
Field order: minute hour day-of-month month day-of-week

Markdown → Word Converter

Paste Markdown and download it as a real .docx file — headings, bold/italic, lists, code blocks, and tables all carry over. Conversion happens entirely in your browser; nothing is uploaded.

Paste Markdown and click convert — a preview of the formatted result will appear here, and a .docx file will download automatically.
