What this is

Thirty-six small tools for the things that come up while working with infrastructure — decoding a certificate, working out why a cron expression fires when it does, checking whether two CIDR ranges collide, reading a Terraform plan, converting between YAML and JSON. No accounts, no limits, no upsell.

Everything runs in your browser

This is the part worth knowing. With one clearly marked exception, every tool here does its work locally in JavaScript. Nothing you paste is uploaded, logged or stored anywhere, because there is no server involved in the processing at all — you can disconnect from the network and the tools keep working.

That matters more in this domain than in most. The things you would naturally paste into a DevOps tool are exactly the things that should not be pasted into a stranger's web form: a Kubernetes manifest with environment variables in it, an IAM policy that describes your account structure, a JWT from a real session, a certificate chain, a .env file. Plenty of online formatters and decoders send all of that to a backend, and a surprising number say nothing about what happens to it afterwards.

The single exception is the AI Rephraser, which cannot work locally because it needs a language model. Its page says so plainly, and it is the only tool that transmits anything.

Why these particular tools

Each one exists because it answers a question that is quicker to look up than to reason about, and that is easy to get subtly wrong from memory — whether 1Gi and 1G are the same number, whether -/+ in a Terraform plan means your database is about to be replaced, whether a cron expression with both a day-of-month and a day-of-week runs on the intersection or the union of the two. Each tool page includes a short reference section covering the mistakes that actually cause incidents, not just the syntax.
